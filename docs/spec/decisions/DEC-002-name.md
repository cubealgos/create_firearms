# `DEC-002` — create_firearms, mod id firearms, display Create: Firearms

**Status:** decided by Kevin, 2026-09-20.

Follows `create_synthetic_diamonds`'s own naming precedent rather than the three earlier siblings':
the folder is the project name, the mod id drops the `create_` prefix, and the Modrinth listing is
titled **"Create: Firearms"** — naming the base mod family, not the specific Create Fly fork, the
same divergence `create_synthetic_diamonds` `DEC-002` already recorded and defended for itself.

same reason every sibling gives: a Create add-on is found by what it does.

No domain registered, no six-TLD availability check run: there is no standalone web presence at
1.0. Revisit trigger: a website for the mod, as for all four siblings.
